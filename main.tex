\section{Question 1}

To show the function \(F\pqty{x} = 2x - 3 \sin x + 5\) has exactly one root, it suffices to consider the region \(\ccintv{-4}{-1}\), since:
\begin{itemize}
    \item if \(x < -4\), then \(F\pqty{x} = \pqty{2x + 5} - 3 \sin x < -3 + 3 = 0\); and
    \item if \(x > -1\), then \(F\pqty{x} > 3 - 3 = 0\).
\end{itemize}

Rearranging \(F\pqty{x} = 0\) to \(2x + 5 = 3 \sin x\), \autoref{fig:question-1-fig} plots the functions in the region concerned.

\begin{figure}[ht!]
    \centering

    \label{fig:question-1-fig}%
\end{figure}

The function \(y = 3 \sin x\) is strictly decreasing on \(\ccintv{-\flatfrac{3\pi}{2}}{-\flatfrac{\pi}{2}} \supseteq \ccintv{-4}{-\flatfrac{\pi}{2}}\), and the function \(y = 2x + 5\) is strictly increasing on that interval, so there is precisely one root on that interval. As for \(x \in \ccintv{\flatfrac{-\pi}{2}}{-1}\), note that \(3 \sin x < 0\) on that interval, while \(2x + 5 > 0\), so there cannot be any roots on that interval.

\section{Question 2}

Suppose after the final binary search iteration, we end up in the interval \(\ccintv{a}{b}\), where the computed values of \(F\pqty{a}\) and \(F\pqty{b}\) satisfy \(F_c\pqty{a} < 0\) and \(F_c\pqty{b} > 0\), and by the requirement of truncation value that \(\flatfrac{\pqty{b - a}}{2} < \num{0.5e-5}\).

If we have \(F_c\pqty{a} < - \delta\) and \(F_c\pqty{b} > \delta\), then \(F\pqty{a} < 0\) and \(F\pqty{b} > 0\), meaning our root must lie in the interval we claimed.

If not, say \(-\delta < F_c\pqty{a} < 0\), then we must have \(-2 \delta < F\pqty{a} < \delta\). Suppose if \(F\pqty{a}\) is of the other sign, i.e., \(0 < F \pqty{a} < \delta\), then its actual value must satisfy, by Taylor's theorem
\begin{equation}
    F\pqty{a} \approx F'\pqty{x_{\ast}} \pqty{a - x_{\ast}}
\end{equation}
and hence rearranging gives
\begin{equation}
    \abs{a - x_{\ast}} \approx \abs{\frac{F\pqty{a}}{F'\pqty{x_{\ast}}}} < \frac{\delta}{4}
\end{equation}
by the hint of \(\abs{F'\pqty{x}} > 4\) and that \(x_{\ast} \in \oointv{-\flatfrac{\pi}{4}}{\flatfrac{-3\pi}{4}}\). Hence, in this case, the accuracy will be approximately
\begin{equation}
    \num{0.5e-5} + \frac{\delta}{4}.
\end{equation}

Mathematically speaking, divergence occurs because of the following. Let \(x_{\ast}\) be a fixed point. Then the iteration satisfies \(f\pqty{x_\ast} = x_\ast\) at the point itself, and for the iteration to converge to the fixed point, if \(x_N\) is near the fixed point, then \(x_{N + 1} = f\pqty{x_N}\), we note
\begin{equation}
    \label{eq:divergence-proof}%
    \begin{aligned}
        x_{N + 1} &= f\pqty{x_N} \\
        &\approx f\pqty{x_{\ast}} + f'\pqty{x_{\ast}} \pqty{x_{N} - x_{\ast}} \\
        &= x_{\ast} + f'\pqty{x_{\ast}} \pqty{x_{N} - x_{\ast}},
    \end{aligned}
\end{equation}
so by rearranging, we have
\begin{equation}
    \label{eq:error-local}%
    \epsilon_{N + 1} \approx f'\pqty{x_{\ast}} \epsilon_{N}
\end{equation}
where \(\epsilon_N = x_N - x_{\ast}\) is the truncation error at the \(N\)-th iteration. It follows that, if \(\abs{f'\pqty{x_{\ast}}} > 1\), then the iteration process cannot converge to the fixed point. For this case where \(k = 0\), note
\begin{equation}
    f'\pqty{x_{\ast}} = \frac{3 \cos x}{2} \approx -1.45021\ldots < -1
\end{equation}
and therefore this iteration process must diverge.

\paragraph{ii. Convergence} Since \(\oointv{-\pi}{-\flatfrac{\pi}{2}}\) is a relatively large interval, we consider the Taylor theorem with the Lagrange reminder, which gives
\begin{equation}
    \label{eq:error-global}%
    \epsilon_{N + 1} = f'\pqty{\xi_N} \epsilon_N
\end{equation}
where \(\xi_N\) lies between \(x_N\) and \(x_{\ast}\) (note that in \autoref{eq:error-local} that this \(\xi_N\) was \(x_{\ast}\)). Therefore, it suffices to have \(f'\pqty{x} \in \oointv{-1}{1}\) for all \(x \in \oointv{-\pi}{-\flatfrac{\pi}{2}}\). We have
\begin{equation}
    f'\pqty{x} = \frac{3 \cos x + k}{2 + k}
\end{equation}
and note that \(\cos\) is increasing in this interval, so therefore this is equivalent to having
\begin{equation}
    f'\pqty{-\pi} = \frac{-3 + k}{2 + k} > -1 \qand f'\pqty{-\frac{\pi}{2}} = \frac{k}{2 + k} < 1,
\end{equation}
the first of which solves to \(\boxed{k > \frac{1}{2}}\), and the second of which always holds given this. Therefore, this is precisely the range of values of \(k\) that convergence is guaranteed.

\paragraph{iii. Monotonic and Oscillatory Convergence} Again, this question concerns the behaviour near the root \(x_{\ast}\), so we recall \autoref{eq:error-local}, and observe that \term{monotonic} convergence corresponds to when \(0 < f'\pqty{x_{\ast}} < 1\) (in which case the error terms have identical signs), and \term{oscillatory} convergence corresponds to when \(-1 < f'\pqty{x_{\ast}} < 1\) (in which case the error terms oscillate between positive and negative).

Choosing \(k = 3\) will give \(f'\pqty{x_{\ast}} > 0\) since \(3 \cos x + 3 \geq 0\), taking equal sign if and only if \(x = \pi + n \pi\) for \(n \in \ZZ\), where \(x_{\ast}\) is certainly not the case. This will give monotonic convergence for a sufficiently good initial guess, and in fact with our initial guess of \(-2\), the program terminates after \(5\) iterations with \(\epsilon = \num{1e-5}\), as plotted in \autoref{fig:question-3-iii-1}.

On the other hand, choosing \(k = 1\) will give \(f'\pqty{x_{\ast}} = -0.63347\ldots < 0\), so we will expect oscillatory convergence for a sufficiently good initial guess, as plotted in \autoref{fig:question-3-iii-2}.

We have from \autoref{eq:error-global} that
\begin{equation}
    \abs{\frac{\epsilon_{N + 1}}{\epsilon_{N}}} = \abs{f'\pqty{\xi_N}} \in \ccintv{\inf \abs{f'}}{\sup \abs{f'}}
\end{equation}
where the infimum and supremum is taken between \(x_N\) and \(x_{N + 1}\). Here, we overestimate this interval by taking this over \(\ccintv{-3}{-2}\) (which covers the whole iteration process), hence by numerical calculations,
\begin{equation}
    \ccintv{\inf \abs{f'}}{\sup \abs{f'}} = \ccintv{f'\pqty{-3}}{f'\pqty{-2}} \approx \ccintv{0.72389\ldots}{0.81953\ldots} \subseteq \ccintv{0.72}{0.82}.
\end{equation}

So after \(34\) iterations, using the bound \(\epsilon \in \ccintv{0.75}{1}\), we have
\begin{equation}
    \epsilon_{34} \in \ccintv{0.72^{34} \epsilon_0}{0.82^{34} \epsilon_0} \subseteq \ccintv{0.75 \cdot 0.72^{34}}{1 \cdot 0.82^{34}} \approx \ccintv{\num{1.05770e-5}}{\num{1.11740e-3}}
\end{equation}
and certainly larger than \(\num{1.0e-5}\). This is consistent with our calculation.

However, \textit{a priori} we would not know that this process converges in 34 steps. Therefore, by rearranging \autoref{eq:error-local}, we have
\begin{equation}
    x_{N + 1} - x_N \approx \pqty{f'\pqty{x_{\ast}} - 1} \pqty{x_N - x_\ast} \approx \frac{f'\pqty{x_{\ast}} - 1}{f'\pqty{x_{\ast}}} \pqty{x_{N + 1} - x_{\ast}},
\end{equation}
which then gives the truncation error in terms of the difference between the terms
\begin{equation}
    \abs{\epsilon_{N + 1}} \approx \abs{\frac{\pqty{x_{N + 1} - x_N} f'\pqty{x_{\ast}}}{f'\pqty{x_{\ast}} - 1}}.
\end{equation}

Putting \(\abs{x_{N + 1} - x_N} = \num{1e-5}\) and \(f'\pqty{x_{\ast}} = 0.72775\), we have \(\abs{\epsilon_N} \approx \num{2.67314e-5}\), which is close to the final two lines of \(\epsilon_N\) in \autoref{tab:question-3-iv}.

\paragraph{v. First-Order Convergence}

Recall from \autoref{eq:error-local}, that in theory, we will have \(\flatfrac{\epsilon_{N + 1}}{\epsilon_N} \approx f'\pqty{x_\ast}\) as \(N \to \infty\). By differentiating, and numerical calculations we have
\begin{equation}
    f'\pqty{x_\ast} \approx 0.01991, -0.63347, 0.72775
\end{equation}
for \(k = 3, 1\) and \(16\) respectively. This matches the data in the \(\flatfrac{\epsilon_N}{\epsilon_{N - 1}}\) column in \autoref{tab:question-3-iii} for \(k = 3\) and \(k = 1\), and \autoref{tab:question-3-iv} for \(k = 16\). This is consistent with the theoretical result of first-order convergence.

\paragraph{Truncation Error and Termination Condition} We therefore expand to a higher order to study the behaviour. We have
\begin{equation}
    \label{eq:second-order-approximation}%
    \begin{aligned}
        x_{N + 1} &= f\pqty{x_N} \\
        &\approx f\pqty{x_\ast} + f'\pqty{x_\ast} \pqty{x_N - x_\ast} + \frac{f''\pqty{x_\ast}}{2} \pqty{x_N - x_\ast}^2 \\
        &= x_\ast + \pqty{x_N - x_\ast} + \frac{f''\pqty{x_\ast}}{2} \pqty{x_N - x_\ast}^2 \\
        &= x_N + \frac{f''\pqty{x_\ast}}{2} \pqty{x_N - x_\ast}^2.
    \end{aligned}
\end{equation}
and hence
\begin{equation}
    x_{N + 1} - x_N \approx \frac{f''\pqty{x_{\ast}}}{2} \epsilon_N^2 \approx \frac{f''\pqty{x_{\ast}}}{2} \epsilon_{N + 1}^2,
\end{equation}
so
\begin{equation}
    \abs{\epsilon_{N + 1}} \approx \sqrt{\frac{2 \pqty{x_{N + 1} - x_N}}{f''\pqty{x_{\ast}}}}.
\end{equation}

Putting in \(x_{\ast} = 4\) gives \(f''\pqty{x_\ast} = - \flatfrac{7}{20} = -0.35\), so we expect \(\abs{\epsilon_{N + 1}} \approx 0.007559\), which matches with the final few lines of data in \autoref{tab:question-4}, and definitely not less than \(10^{-5}\).

\paragraph{Asymptotic behaviour of \(\epsilon_N\)} We claim that \(\epsilon_N \sim \flatfrac{40}{\pqty{7N}}\), which is clearly the behaviour demonstrated in \autoref{tab:question-4} (although very slowly -- the data was extended to the \(N = 5000\) iteration). If this claim were true, then \(\flatfrac{\epsilon_N}{\epsilon_{N - 1}} \to 1\) which is not first-order convergence.

To prove this claim mathematically, we rearrange \autoref{eq:second-order-approximation} to get 
\begin{equation}
    \epsilon_{N + 1} \approx \epsilon_N + \frac{f''\pqty{x_{\ast}}}{2} \epsilon_N^2 = \epsilon_N - \frac{7}{40} \epsilon_N^2,
\end{equation}
and seeking for an ansatz of the form \(\epsilon_N ~ \flatfrac{k}{N}\) gives \(\flatfrac{1}{N + 1} \sim \flatfrac{1}{N} - \flatfrac{7 k}{40 N^2}\), and note \(\flatfrac{1}{N + 1} - \flatfrac{1}{N} \sim \flatfrac{1}{N^2}\) so \(k = \flatfrac{40}{7}\) as claimed.

\subparagraph{Rate of Convergence} Consider expanding the iteration expansion about \(x_{\ast}\),
\begin{equation}
    \label{eq:rate-of-convergence-newton-raphson-single-root}%
    \begin{aligned}
        x_{N + 1} &= x_N - \frac{f\pqty{x_N}}{f'\pqty{x_N}} \\
        &= x_N - \frac{f\pqty{x_\ast} + \pqty{x_N - x_{\ast}} f'
        \pqty{x_{\ast}} + f''\pqty{x_{\ast}}\flatfrac{\pqty{x_N - x_{\ast}}^2}{2} + \cdots}{f'\pqty{x_\ast} + f''\pqty{x_{\ast}}\pqty{x_N - x_{\ast}} + \cdots} \\
        &= x_N - \pqty{x_N - x_{\ast}} \frac{f'\pqty{x_{\ast}} + f''\pqty{x_{\ast}} \flatfrac{\epsilon_N}{2} + \bigO\pqty{\epsilon_N^2}}{f'\pqty{x_{\ast}} + f''\pqty{x_{\ast}} {\epsilon_N} + \bigO\pqty{\epsilon_N^2}} \\
        &= x_N - \pqty{x_N - x_{\ast}} \pqty{1 + \frac{f''}{f'} \frac{\epsilon_N}{2} + \bigO\pqty{\epsilon_N^2}} \pqty{1 - \frac{f''}{f'} \epsilon_N + \bigO\pqty{\epsilon_N^2}},
    \end{aligned}
\end{equation}
and hence subtracting \(x_{\ast}\) on both sides,
\begin{equation}
    \begin{aligned}
        \epsilon_{N + 1} &= \epsilon_N \pqty{1 - \pqty{1 + \frac{f''}{f'} \frac{\epsilon_N}{2}} \pqty{1 - \frac{f''}{f'} \epsilon_N}} + \bigO\pqty{\epsilon_N^4} \\
        &= \pqty{\frac{f''\pqty{x_{\ast}}}{2f'\pqty{x_{\ast}}}} \epsilon_N^2  + \bigO\pqty{\epsilon_N^3}.
    \end{aligned}
\end{equation}

This is indeed second-order convergence in theory. By calculation, \(\flatfrac{f''\pqty{x_\ast}}{2 f'\pqty{x_{\ast}}} \approx -0.07820\). Observing in the final column \autoref{tab:question-5-eq-4-converge}, this data matches with entries \(N = 3, 4\), as expected.

\subparagraph{Rate of Convergence} Note at a double root, not only \(f\pqty{x_{\ast}} = 0\), we also have \(f'\pqty{x_{\ast}} = 0\). Expanding as \autoref{eq:rate-of-convergence-newton-raphson-single-root}, suppose \(f''\pqty{x_{\ast}} \neq 0\), we get
\begin{equation}
    \begin{aligned}
        x_{N + 1} &= x_N - \frac{f\pqty{x_N}}{f'\pqty{x_N}} \\
        &= x_N - \frac{f\pqty{x_\ast} + \pqty{x_N - x_{\ast}} f'
        \pqty{x_{\ast}} + f''\pqty{x_{\ast}}\flatfrac{\pqty{x_N - x_{\ast}}^2}{2} + \cdots}{f'\pqty{x_\ast} + f''\pqty{x_{\ast}}\pqty{x_N - x_{\ast}} + \cdots} \\
        &= x_N - \frac{\epsilon_N}{2} + \bigO\pqty{\epsilon_N^2}
    \end{aligned}
\end{equation}
and hence
\begin{equation}
    \epsilon_{N + 1} = \frac{\epsilon_N}{2} + \bigO\pqty{\epsilon_N^2}
\end{equation}
gives a theoretical first-order convergence, and with \(C = \frac{1}{2}\), which is identical to a simple bisection method. Comparing with data in \autoref{tab:question-5-eq-5} (where we added extra lines to \(N = 26\) corresponding to \(\num{1e-20}\)), we note that the second-from-last column is relatively consistent with out claim of \(\frac{1}{2}\), but for the final few rows, this deviates from theory, since \verb|numpy| \verb|float64| type lost precision in calculations for \(x_N\) when the error goes below approximately \(\sim \num{1e-15}\) (i.e. near row 25).

\subparagraph{Rounding Error} For a double root, the rounding error is more significant, since \(F'\pqty{x_{\ast}} = 0\), and dividing by the derivative will significantly amplify the error in evaluating \(F\) near \(x_{\ast}\).
